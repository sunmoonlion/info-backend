## 做什么

输入是年报一页一页的词和坐标，输出是三张**合并**报表的每一行：科目名、本期数、上期数。

| 步骤 | 做法 |
| --- | --- |
| 找报表 | 认标题：`合并资产负债表`、`合并利润表`、`合并现金流量表`。标题前的序号、印在同一行的期间、续页的「(续)」先去掉 |
| 找结束 | 遇到下一张表的标题（母公司报表、所有者权益变动表等）就结束。标题下面一个数都没有就到了下一个标题的，是报表目录，不算 |
| 认单位 | 见下面「单位从哪里认」 |
| 拼数 | PDF 里一个数偶尔被拆成两个贴在一起的词（「21,65」「0,419」），先拼回去 |
| 分列 | 数字右对齐，右边缘最集中的两处就是本期、上期两列。每页单独分；只有一两行的页借相邻页的位置 |
| 抽行 | 一行里落在这两列位置上的数字各取一个；不在这两列上的数字（附注编号、正文里的金额）不取 |
| 认科目 | 科目名归一化之后对财务目录；折成两三行的科目名拼回去再认 |
| 勾稽 | 财务目录里的九条同期规则，本期、上期两列各做一遍 |
| 量级核对 | 拿参照数（别的来源的同一个科目）比：差一千倍、一万倍、一百万倍左右的，是单位认错了 |

全部是确定性的计算，不调用任何模型（规则 `C-A9`）。

### 单位从哪里认

| 顺序 | 位置 | 记为 | 可信程度 |
| --- | --- | --- | --- |
| 1 | 标题下面、第一行数字之前（表头里） | `statement_page` | 报表自己写明的 |
| 2 | 同一页上标题的上方，离标题最近的那一处 | `above_title` | 要用参照数核对量级 |
| 3 | 财务报表开头说过一次「报表的单位为」 | `declared_elsewhere` | 要用参照数核对量级 |

第一行数字之后再出现的「人民币元」不算（利润表末尾的「基本每股收益（人民币元）」）。
「财务附注中报表的单位为：千元」说的是附注，不当作紧挨着的那张表的单位，只算第 3 种。

这个顺序是比亚迪的年报教的：它在资产负债表标题的上一行写「财务附注中报表的单位为：人民币千元」，
标题下面写「单位：元」。探针取了页面上第一处单位，把四张资产负债表认成了千元，数大了一千倍。

## 数是原样的

| 项 | 约定 |
| --- | --- |
| 金额 | 精确十进制（`Decimal`），年报上印几位就是几位 |
| 单位 | 不乘。抽出来的数是年报上印的数，单位另外记着 |
| 符号 | 不改。括号和负号都读成负数；有的公司把成本印成负数，照原样 |
| 科目名 | 去掉空白之后的原样，连序号和附注编号一起留着；归一化只用于认科目 |
| 没对上目录的行 | 照样保留。目录里没有的科目不会丢，只是没有字段名 |

## 认不出就拒绝

哪张表认不出来，那张表就不给出任何数，原因记在 `problems` 里；别的表不受影响。

| 错误码 | 含义 |
| --- | --- |
| `statement_not_found` | 没找到这张表的标题 |
| `section_end_not_found` | 找到了开头，读到最后也没遇到下一张表 |
| `section_too_long` | 超过 8 页还没结束 |
| `unit_not_stated` | 报表页上没写单位，别处也没声明过 |
| `no_amounts` | 这张表里没有可以定列的数字 |
| `broken_amount` | 落在列位置上的一个词像数又不是合法的数（「238,400,00」「0,419」）：读到半个数比读不到更糟 |
| `one_column` | 某一页只有一列数字，分不清是本期还是上期 |
| `more_than_two_columns` | 某一页有三列以上密集的数字 |
| `expected_four_columns_found_N` | 并排的版式应该有四列，实际找到 N 列 |
| `two_amounts_in_one_column` | 一行里有两个数落在同一列上 |
| `amounts_on_a_page_without_columns` | 某一页定不了列，上面却有金额 |

勾稽不平不在上表里：抽取照常给出结果，由 `reconcile` 说哪条规则、哪一列、差多少。
用不用这张表由调用的一方决定；设计上不平就不该入库（`F-INFO-14`）。

## 怎么用

```python
from app.application.securities.report_extraction import (
    check_unit, extract_statements, reconcile, resolve,
)
from app.infrastructure.securities.pdf_words import PdfPlumberWordsReader

pages = PdfPlumberWordsReader().read_words(pdf_bytes)   # 从第 12 页起，逐页给
found = extract_statements(pages)                        # 三张表都结束就不再往下读
for name, statement in found.statements.items():
    lines = resolve(name, statement.rows)                # 认科目
    checked, broken = reconcile(statement, lines)        # 勾稽
    verdict, _ = check_unit(statement, lines, reference) # 量级；reference 是以元计的参照数
```

## 在存档年报上的结果（2026-09-28）

十四家公司、117 份年报（同一年有更正版的取公告编号最大的一份），不访问网站。
原始记录在 `app/scripts/results/report-extraction-archive.20260928-*.txt`。

| 项 | 结果 |
| --- | --- |
| 抽到的表 | 339 张，共 351 张。没抽到的 12 张都有明确的原因，见下 |
| 带数字的行 | 14065 行；其中对上财务目录的 5619 行 |
| 勾稽 | 做了 1864 次，不平 18 次：美的集团 16 次，中芯国际 2 次 |
| 单位 | 有第三方数据可比的 298 张，量级全部一致 |
| 与探针逐行对照 | 338 张可比，332 张逐行相同；不同的 6 张都是美的集团，是探针读错了 |

没抽到的 12 张：

| 公司 | 年份 | 表 | 原因 |
| --- | --- | --- | --- |
| 万科A | 2017、2018 | 资产负债表 | `more_than_two_columns` |
| 中国中免 | 2021 | 利润表 | `more_than_two_columns` |
| 美的集团 | 2023、2024 | 利润表 | `expected_four_columns_found_3` |
| 比亚迪 | 2018 | 现金流量表 | `broken_amount`，PDF 里有一个残缺的数「238,400,00」 |
| 比亚迪 | 2023 | 三张 | `unit_not_stated` |
| 紫金矿业 | 2025 | 三张 | `statement_not_found`。财务报表那十几页是图片，没有词 |

勾稽不平的 18 次：

| 公司 | 次数 | 原因 |
| --- | --- | --- |
| 美的集团 | 12 | 所得税费用印成负数。`reconcile` 指出「把所得税费用反号就平」 |
| 美的集团 | 2 | 2018 年资产负债表的「少数股东权益」在 PDF 里是乱码（「计算少数ji计股东权益」），没认出来，差额正好等于它 |
| 美的集团 | 2 | 2025 年利润表的所得税费用没认出来 |
| 中芯国际 | 2 | 所得税费用印成负数 |

这些原因是逐条看过的。对探针报告的更正：探针里说美的集团「13 处不平我判断都是符号，没有逐个核实」，
核实的结果是其中有一部分是探针把数读错了（被拆开的数只读到后半截），不全是符号。

## 已知的限制

| # | 限制 | 后果 |
| --- | --- | --- |
| 1 | 只抽合并报表；母公司报表、所有者权益变动表不抽 | 所有者要不要母公司报表还没定 |
| 2 | 只认文字型 PDF。扫描件没有词，三张表都是 `statement_not_found` | 老年报可能是扫描件，没有试过 |
| 3 | 财务目录现在每张表只有二三十个字段 | 多数行抽到了但没有字段名。统一的科目表是段九 |
| 4 | 单位不是报表自己写明的（`above_title`、`declared_elsewhere`），认到的可能不对 | 必须有参照数做量级核对才能用 |
| 5 | 拼行按词的高度分组，对坐标的微小差别敏感 | 夹具里的坐标保留两位小数；少一位会让个别表头行的拼法变化，带数字的行没有受影响的例子 |
| 6 | 把成本印成负数的公司，勾稽规则会不平 | `reconcile` 会指出「把哪个科目反号就平」，但不替它改 |
| 7 | 金融类公司的报表格式不同 | 没有试过 |
| 8 | 被拆开的数只有两个词贴在一起时才拼得回去 | 拆开后不贴在一起的，如果后半截恰好是个合法的数，会被当成那个数读进来。参与勾稽的科目能被勾稽发现，不参与的发现不了。十四家里没有见到这种情况，但不能排除 |
| 9 | 一张表没有任何一条勾稽规则能做（所需科目没认全）时，等于没有验证 | 美的集团的现金流量表就是这样。入库时应该要求至少做过一次勾稽 |
| 10 | 十四家都是大公司 | 小公司的年报版式可能更不规范 |
